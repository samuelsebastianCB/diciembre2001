Cómo se construyó este proyecto

Aplicación de una sola página (SPA) en Angular con componentes standalone, signals y rutas con carga diferida, compilada con ng build y desplegada en Firebase Hosting.

⚙️ Framework

Angular (standalone components, signals, control flow @if / @for).

🧭 Navegación

Angular Router con loadComponent (lazy loading) por página.

🗄️ Base de datos

No se usa BD: los datos viven en src/app/data/eventos.ts y se compilan en el bundle.

☁️ Hosting

Firebase Hosting sirve dist/diciembre2001/browser por HTTPS y CDN global.
